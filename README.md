# راهنمای فارسی OrcaSlicer
تهیه‌کننده و نگه‌دارنده‌ — امید طاهری (Omid Taheri)، حساب GitHub با نام coolboysalam.

بستهٔ غیررسمی ترجمهٔ توضیحات تنظیمات (Tooltip / Help) برای OrcaSlicer ویندوز. زبان برنامه را روی English قرار دهید.

| نسخهٔ برنامه | بسته | پوشش ممیزی |
|---|---|---|
| 2.4.2 | V2، شامل ۶۹۸ کلید ترجمه | ۶۷۸ از ۶۸۰ راهنمای یکتا طبق گزارش همراه بسته |
| 2.5.0 | V3.5، شامل ۸۰۲ کلید دقیق نسخه | ۸۰۲ از ۸۰۴ راهنمای یکتا، ممیزی مجدد انجام شده |

شمارش محدود به راهنماهای استخراج‌شده از PrintConfig.cpp است. دو متن Enable clumping detection و Enable filament ramming با عنوان گزینه مشترک‌اند و انگلیسی نمایش داده می‌شوند. تعداد کل کلیدهای بستهٔ ۲.۴ شامل کلیدهای سازگاری است، بنابراین با تعداد کلیدهای ممیزی یکسان نیست.

## دریافت و نصب
بستهٔ سازگار با نسخهٔ برنامه را از پوشهٔ packages دریافت و کامل استخراج کنید. OrcaSlicer را ببندید و Install.cmd را اجرا کنید. نصب در Program Files به دسترسی Administrator نیاز دارد. مسیر پیش‌فرض C:\Program Files\OrcaSlicer است. راهنمای نصب سفارشی و بازیابی در docs/INSTALL_FA.md آمده است.

## محتوا و محدودیت‌ها
بستهٔ ۲.۵ شامل MO، دادهٔ ترجمهٔ JSON، جدول ۸۰۴ راهنما، اسکریپت ممیزی، نصب‌کننده و بازیابی است. بستهٔ ۲.۴ دادهٔ ترجمه، PO، ابزار ساخت و نصب‌کنندهٔ خودش را دارد.
ممیزی کاتالوگ ۲.۵ پوشش ۸۰۲/۸۰۴ را تأیید کرده است. نصب‌کننده‌ها در این محیط روی ویندوز اجرا نشده‌اند و بررسی دیداری تمام متن‌ها در رابط برنامه تکمیل نشده است.
وب‌سایت کامل فارسی و تصاویر Wiki در این بسته‌ها قرار ندارند. نسخهٔ محلی راهنما پروژهٔ بعدی است.
